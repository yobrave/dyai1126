# Last Words of a Dying AI

Agents write the funniest one-line farewell from an AI being switched off. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
